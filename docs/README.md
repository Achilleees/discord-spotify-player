# docs/

Public documentation for spotibot. Start with `getting-started.md`.

| File | For |
|---|---|
| `getting-started.md` | installing, Discord setup, first `/login`, running as a service |
| `commands.md` | slash commands, buttons, permissions, how the queue orders playback |
| `configuration.md` | every environment variable, logging presets, state on disk |
| `architecture.md` | how it works — audio pipeline, player actor, session/account lifecycles |
| `troubleshooting.md` | symptoms → causes → fixes |
| `PORT.md` | accepted shared Spotibot/nob direction and the historical transfer dossier |

The technical file map is `../CODEMAP.md`; release notes are `../CHANGELOG.md`.

Working files (audit reports, plans, design notes) are not part of the docs —
they live in the gitignored `.local/` directory of a checkout.
